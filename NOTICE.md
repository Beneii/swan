# Provenance and rights

Swan is an unofficial experimental custom coordinator harness. Its local desktop prototype adapts an installed Capy 0.4.7 application. Capy's interface and original application remain attributable to their respective owners. Claude and Claude Code belong to Anthropic.

The custom backend modules and tests were developed for this prototype. Compatibility adapters reference local extracted Capy contracts, which are not distributed here. Screenshots illustrate the adapted application running isolated test workflows; they do not imply ownership of the underlying interface or endorsement by its authors.

No Capy executable, renderer bundle, extracted schema, signed application package or bundled runtime is distributed in this repository. Do not interpret these sources or screenshots as authorization to redistribute Capy. A public repository is not itself an open-source license; no blanket redistribution license is asserted here.

The backend package lock references the independently distributed `ws` dependency. Its own license applies when obtained separately. The public core test subset does not need it installed.
